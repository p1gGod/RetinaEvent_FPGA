# v7b 部署裁决与风险接受（Lead 决定记录）

记录时间：2026-10-31 01:15 左右。记录人：Team Lead。
适用对象：作为 act8 位流权重来源的 v7b 模型（nn/out_v7b/，训练口径见 nn/REPORT_v7b_部署口径重训.md）。

## 1. 结论

1. v7b 的自动判据 `V7B_MODEL_OK` 记为 **0**（未达标），不修改门限、不挑选随机种子、不重跑结果直到达标。
2. 尽管如此，v7b 权重仍然作为 act8 位流的部署权重。这是一次**显式的风险接受决定**，理由与代价在下面写清。
3. 部署参数取 `MARGIN_MIN = 16`、`N_CONSEC = 3`、不应期 1.5 s、决策节拍 100 ms 非重叠窗。

## 2. 为什么判据记 0

下表是 v7b 在部署口径（s100，100 ms 非重叠窗，guard 0.5 s）下的实测与门限对照。

| 判据项 | 门限 | 实测 | 结论 |
| --- | --- | --- | --- |
| A 组开合块召回 | ≥ 17/17 | 17/17 | 通过 |
| A 组挥手 pulse | ≤ 1 | 1 | 通过 |
| A 组手静止误触发 | 0 次每分 | 0 次每分 | 通过 |
| A 组空桌面误触发 | 0 | 0 | 通过 |
| A 组硬负样本 pulse | ≤ 1 | 2（卷纸 1、打字 1） | **未通过** |
| C 组镜像迁移 d_wave | ≤ 0.01 | 0.0196（int8） | **未通过** |

两项未达标都如实写进报告与证据，不做「取整后通过」或「换口径后通过」的表述。

## 3. 为什么仍然用它

同一套 s100 评估集上，v7 权重（用 s50 训练）与 v7b 权重的对比如下。

| 指标 | v7 权重（s50 训练） | v7b 权重（s50+s100 混合训练） | 变化 |
| --- | --- | --- | --- |
| 开合块召回 | 17/17 | 17/17 | 不变 |
| 挥手 pulse | 5 | 1 | 减少 4 |
| 硬负样本 pulse | 5 | 2 | 减少 3 |
| 手静止误触发 | 0 次每分 | 0 次每分 | 不变 |
| 空桌面误触发 | 0 | 0 | 不变 |

v7b 在部署口径下对 v7 权重的四项指标全部不劣，其中两项明显改善，因此没有理由继续用 v7 权重上板。

关于两项未达标：

- 硬负样本（打字、端纸杯）来自摄像头转向键盘后的 view B 视角，与部署视角不同；且评估用的是同一场景的另一半时间窗，属时间外推而非完全分布外。实测 2 次 pulse 对应约 46.5 s 素材，折算约 2.6 次每分，高于 1 次每分的内部目标，这一数字必须原样披露。
- 镜像迁移 d_wave 由 v7 的 0.0078 退化到 0.0196，方向是左右手通用性。这是 s100 混合训练带来的副作用，写进限制章节，不通过改门限掩盖。

## 4. 决定接受的风险

1. 打字等桌面操作在部署视角下可能触发少量误报，实测依据只有 view B 的 46.5 s 素材，部署视角下的真实误报率仍未知，须由 A1~A4 上板验收给出。
2. 左右手通用性弱于 v7，左手动作的检出可能依赖同一只手的位置稳定性。
3. 位流时序余量仅 0.059 ns（act7 实测），act8 若 WNS 转负必须回退到 act7 或改版，不得以「仿真通过」替代时序证据。

## 6. 复查条件

1. 上板验收 A1~A4 若出现「手在画面静止仍有动作报出」，本决定立即失效，改回保守配置并重训。
2. 若 act8 时序不收敛，本决定同样失效，回退 act7 权重（此时必须把 v7 在 s100 下的退化数字一并写进报告）。
