## 2 三份文档的分工边界

避免同一内容写三遍、三处数字打架。

- **D1 设计报告**：讲「为什么这样设计」。原理、软硬件划分依据、接口契约、优化路径与判断依据、复现步骤。数值只引用不展开推导。
- **D2 评测报告**：讲「实测到什么」。测量方法、原始数据、图表、与参考结果（离线模型 / 黄金向量 / 厂商例程）的比对、误差与失效边界。不做设计论证。
- **D3 协作记录**：讲「怎么和模型协作的」。任务书模板、机读判据、模型输出被驳回的具体案例、纠正后的产出差异。
- **D4 技能包**：把 D3 里的经验做成他人可直接套用的目录（提示词模板 / 脚本 / 清单），三项独立可用、互不依赖。

交叉引用用相对链接，不复制段落。

## 3 文风硬规则

目标读者是评委，不是队友。按产品级技术报告写。

### 3.1 结构

1. **结论先行**：每章第一段是结论句（"本章给出 X 的实测结果：A 为 a，B 为 b"），随后才是论据。
2. **金字塔**：章 → 节 → 要点，最多三层，不写四层及以下的标题。
3. **一节一图或一表**：凡有对比、分布、流程、时序，先用图表，文字只解释"这张图说明什么"。
4. **判断依据优先于结论**：写"选了 A 因为 B 测试给出 c"，不写"选用了先进方案 A"。
5. 段落 3~5 句，单句不超过 60 字；不用抒情、不用感叹号、不用设问句。

### 3.2 禁用与替换

| 禁用（AI 味 / 空话） | 改用 |
|---|---|
| 不是……而是…… | 直接陈述事实；或"A 为 x；B 为 y" |
| 首先 / 其次 / 最后（作段落骨架） | 用编号（1、2、3）或不编号，直接分点 |
| 值得注意的是 / 不难发现 / 众所周知 | 删掉，直接写事实 |
| 赋能、打造、助力、闭环、痛点、一站式、多维度 | 删掉，写具体动作用词（实现、降低、缩短、覆盖） |
| 显著提升 / 极大地 / 大幅 / 完美 | 给出数字："从 46 次/分降到 0 次" |
| 我们认为 / 笔者以为 / 可以说 | 删掉主语，直接给结论 |
| 综上 / 总而言之 | 用"结论"小标题，或直接给数字 |
| 深度学习赋能 / 智能识别 | "int8 二分类卷积网络，208,080 MAC/窗" |
| 赋能硬件 / 硬件加速（作为口号） | 写清加速对象与倍数 |

### 3.3 数字

1. **每个数字必须能溯源**：正文中首次出现时，括号注源文件相对路径（如 `（build/variant_act3c/timing_deliver.rpt）`）。D2 的表格全部带"数据来源"列。
2. **同一数字只允许一个权威出处**，统一在 D8 口径登记表登记；其它文档引用登记表。
3. 不确定的数字不写；用"未测量"或"本版未覆盖"明确标注。
4. 单位统一：时钟 MHz、时间 ms / us、资源用绝对值 + 占比（`20,559 / 63,400 = 32.43%`）、速率用 `次/分`、事件率用 `事件/秒`。

### 3.4 语言

- 中文正文，术语保留英文原词（int8、BRAM、WNS、UART、HUD 等），首次出现给中文解释。
- 不用第一人称复数口号式表达；团队动作以"本设计 / 本工程"指代。
- 不用"我们"，需要指实施主体时写"上位机 / 板上引擎 / 训练侧"。

## 4 关键口径（防止两处不一致，最终以 D8 登记表为准）

| 项 | 口径 |
|---|---|
| 器件 | AMD Artix-7 `xc7a100tfgg484-2`（正点原子达芬奇Pro） |
| 工具版本 | Vivado 2020.2、ModelSim SE 2020.4（指南推荐 2026.1/2025.2，报告须说明并给可复现脚本） |
| 板上位流 | `variant_act8_final`，2026-10-31 02:02 烧录，2,839,107 B，md5 `5ec55ec07c44f2503df63f1bb160a6e6`；act3c 2,890,875 B 为历史版本 |
| 时序 | act8 final 布线：WNS `+0.215 ns`、TNS 0、WHS `+0.017 ns`、THS 0（`variant_act8_final/timing.rpt`）；act7 `+0.059 ns`、act3c `+0.306 ns` 为历史版本 |
| 实现资源 | act8 final：LUT 22,383（35.30%）/ FF 14,325（11.30%）/ Slice 8,026（50.64%）/ BRAM 86.5（64.07%）/ DSP 8（3.33%）/ IOB 140（49.12%）；act3c 资源为历史版本 |
| 神经网络 | int8 两分类（v7b），每 100 ms 窗一次推理；v7b 推理耗时未单独实测，8.80 ms（440,087 拍 @50 MHz，占空比 8.8%）为 v5/act3c 基线，不可直接套用 |
| 决策节拍 | 窗 100 ms 不重叠；连续 3 窗同类锁存（`N_CONSEC=3`）；判据门限 `NN_MARGIN_MIN=16`；不应期 1.5 s；空窗 1.0 s 清零 |
| 事件坐标 | events.csv 为 400×240 原始像素；网格 50×30（>>3）；**像素量不能直接当网格量用** |
| 误触发门限 | `< 1 次/分`（官方未规定，本队自定验收门限） |
| 计率口径 | `次/分 = pulse 数 ÷ (决策点数 × 100 ms)`；zone 首尾各 0.5 s 守卫带不计 |
