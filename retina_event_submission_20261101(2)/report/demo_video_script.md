# RetinaEvent 演示视频分镜脚本

> 用途：3 分钟演示视频，按本脚本一次拍成。
> 硬上限：180 s；本脚本总长 175 s。
> 讲解词为中文口语，每句不超过 25 字；拍摄时不念旁白以外的文字。

## 2. 拍摄清单

### 2.1 设备与场地

- 开发板：正点原子达芬奇Pro，XC7A100T-FGG484-2；已烧录 variant_act8_final（2026-10-31 02:02 烧板，PROG_RESULT=OK / DONE_PIN=1 / EOS=1）。
- 摄像头：OV5640 模块，排线固定，镜头不抖动。
- 网络：网线接底板 GE1；PC 以太网静态 192.168.1.102/24。
- 主机：运行上位机面板的同一台 PC；屏幕亮度固定，关闭通知与弹窗。
- 拍摄：手机或相机固定在三角架上；主机位与屏幕成 15 度以内，避免摩尔纹。
- 灯光：顶部白光常亮，避免窗外自然光突变；桌面背景用纯色或干净墙面。

### 2.2 开拍前彩排两遍

1. 第一遍只走位：确认每个镜头的起止时间、手的位置、鼠标点击点。
2. 第二遍带录制：确认事件曲线、动作计数、录制回放、标注工具都能按脚本出现。
3. 彩排时用秒表核对总长，超过 180 s 就压缩 00:10–00:30 的静止段，不压缩动作与复现段。

### 2.3 失败重拍判据

- 事件率曲线在静止段持续跳动：检查灯光、摄像头自动曝光、桌面是否有风扇或窗帘。
- 开合动作不触发：检查手是否在画面中央、动作幅度是否足够、动作卡片是否已连接。
- 录制没有文件：检查 records 目录权限与磁盘空间，先做一次 10 s 试录。
- 回放音画不同步：以 frames.csv 的 frame_idx 与 t_board_ms 为准，不用容器时间轴判断。
- 收尾画面出现队伍信息：立即重拍，海报与视频都不允许出现学校、姓名、联系方式。

## 3. 剪辑与交付

- 输出 1920×1080、H.264、30 fps；总时长不超过 180 s；文件不超过 300 MB。
- 保留原始拍摄素材与一次未剪辑版，便于平台复核。
- 字幕只保留讲解词，不叠加长段说明；数据数字与 D8 登记册一致。
- 封面帧使用板卡与屏幕同框的画面，不额外制作 PPT 封面。
