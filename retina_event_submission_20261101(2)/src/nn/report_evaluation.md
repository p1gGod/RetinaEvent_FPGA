## 2. 官方固定 test 结果（float 与 int8）

- float：acc=0.915344，balanced=0.932773；
  混淆矩阵 [[70,0,0],[8,103,8],[0,0,0]]。
- int8：acc=0.957672；
  混淆矩阵 [[70,0,0],[8,111,0],[0,0,0]]。
- 每类（float）：class0 P=0.8974 R=1.0000（n=70）；class1 P=1.0000 R=0.8655（n=119）。
- int8 与 float 的差别只涉及 8 个 class1 窗口：float 把它们判成 class2，int8 判成 class1。
  两个模型对 class0 的 70 窗全部判对，class1 仍有 8 窗被判成 class0。
- 189 窗的 95% Wilson 置信区间约 [0.867, 0.947]（按独立同分布算；窗间 50 ms 重叠，
  实际区间更宽）。因此 0.915 与 0.958 的差距（8 窗）不能作为量化优劣的证据。

| 4 | 192251,192720,204439,212036 | 375 | 0.7547 | 0.7186 | 73 | 0.6027 |
| 汇总 | 全部 20 会话 | 1729 | 0.8346 | 0.7599 | 205 | 0.5415 |

汇总混淆矩阵（行=true，列=pred，顺序 0/1/2）：

    [[765,  32,  26],
     [ 47, 567,  87],
     [  6,  88, 111]]

每类 precision / recall / F1：

| 类 | support | precision | recall | F1 |
|---|---|---|---|---|
| class0 无动作/板移 | 823 | 0.9352 | 0.9295 | 0.9324 |
| class1 手部开合 | 701 | 0.8253 | 0.8088 | 0.8170 |
| class2 横向挥手 | 205 | 0.4955 | 0.5415 | 0.5175 |

读法：
- class0 与 class1 在跨会话 CV 下仍有 0.81~0.93 的召回，说明“有手部开合动作/无动作”
  的主信号是可学的；class1 的 87 个错误里有 47 个被判成 class0、87 个里有一部分是
  活动段边缘窗（标签按 50% 重叠），边缘噪声占一定比例。
- class2 是明显短板：205 窗里只有 111 窗召回，88 窗被判成 class1、6 窗被判成 class0；
  三折 class2 recall 从 0.19 到 0.76，方差极大。原因是 class2 只有 3 条会话，每折训练
  时只剩 2 条 class2 会话，模型很容易学到“某条会话的纹理”而不是挥手本身。
- 折 0 没有 class2，balanced accuracy 只在 class0/class1 上平均；折 1 的 0.949 也是
  两类口径，不能与 3 类折直接比较。
- 按会话分组避免了同会话窗口泄漏，但同一会话内的窗口仍高度相关（100 ms 窗、50 ms 步进），
  有效独立样本远小于 1729；不要把 ±1.7 pp 的朴素二项误差当成真实置信区间。

## 4. 留一参数组 CV

按 M1 的参数组 (θ,Δ) 留出一整组训练/测试（train.py 的 train_one 同超参，seed 变化）：

| 留出组 | test n | acc | balanced | 混淆矩阵 |
|---|---|---|---|---|
| θ1Δ20 | 368 | 0.9538 | 0.9346 | [[238,0,0],[7,113,10],[0,0,0]] |
| θ1Δ32 | 227 | 0.9295 | 0.9372 | [[73,3,0],[12,138,1],[0,0,0]] |
| θ3Δ18 | 1134 | 0.7540 | 0.6145 | [[462,47,0],[27,393,0],[3,202,0]] |

关键发现（必须如实写）：
- class2（横向挥手）的 3 条会话全部属于 θ3Δ18。留出 θ3Δ18 时，训练集里一条 class2
  都没有，模型只能把 class2 判成 class0/class1（实测 202/205 判成 class1）。
  因此这一折的 0.7540 **不能**解读为“3 类模型在 θ3Δ18 上的真实精度”，而是
  “训练集缺类时必然失败”的结构性证据。
- 前两组（θ1Δ20、θ1Δ32）没有 class2 test，它们的 0.95/0.93 只说明 class0/class1
  在两个参数组间可迁移；class1 在 θ1Δ32 上仍有 12+1 个错误。
- 结论：不能用“留一参数组 CV”给 3 类模型打分；它适合证明 class0/class1 的跨组稳定性，
  而 class2 的跨组评估必须补新的参数组/会话（目前所有 class2 都落在同一组）。

## 5. ON/OFF 通道消融（官方 test，70 class0 + 119 class1）

把某一输入通道整层置零，观察准确率变化；float 与 int8 同时测：

| 置零通道 | float acc | float 掉点 | int8 acc | int8 掉点 |
|---|---|---|---|---|
| 无（baseline） | 0.9153 | - | 0.9577 | - |
| ON_now | 0.9259 | -1.06 pp | 0.9577 | 0.00 pp |
| OFF_now | 0.9153 | 0.00 pp | 0.9418 | +1.59 pp |
| ON_prev | 0.9153 | 0.00 pp | 0.9524 | +0.53 pp |
| OFF_prev | 0.9471 | -3.17 pp | 0.9471 | +1.06 pp |

读法：
- 在这 189 窗上，没有任何单个通道是决定性的；float 去掉 ON_now 或 OFF_prev 反而略升，
  说明模型在这批数据上存在冗余/过拟合，通道消融没有呈现出“ON/OFF 任一通道不可替代”。
- int8 一侧 OFF_now 掉点最大（1.59 pp），ON_prev 最小（0.53 pp），但差异只有 1~3 个窗口，
  在 189 窗上不显著。
- 该消融**没有覆盖 class2**（官方 test 无 class2），因此不能据此判断挥手时 ON/OFF
  哪路更关键；这是本评估的已知盲区，后续应在 class2 会话上做同样消融。

## 6. M1 每类窗口数与样本量置信度边界

- w100 数据集（本次训练）：总 1729 窗；class0=823（其中 board_move=95）、class1=701、
  class2=205。每类非重叠估计（按 50 ms 步进 / 100 ms 窗折算）约 class0=412、
  class1=350、class2=103。
- class2 只有 3 条独立会话（210102/211950/212036），且 3 条都是 θ3Δ18、同一批采集条件；
  class0 的 95 个 board_move 窗只来自 1 条会话（210307）。
- 置信度边界：
  - 官方 test 189 窗，95% Wilson CI 约 [0.867, 0.947]；8 窗差异 ≈ 4.2 pp，处于噪声量级。
  - 5 折 CV 的 acc 折间范围 0.7547~0.9490（极差 19.4 pp），说明“换一批会话”带来的
    方差远大于同一 test 上的小数点差异；报告 0.8346 时必须同时给出这个范围。
  - class2 recall 0.5415 的朴素 95% CI 约 [0.473, 0.610]，但只有 3 个会话簇，
    簇间方差远大于二项方差；折间 0.19~0.76 才是更诚实的边界。
  - 按 M1 SEP3 的 ridge 跨会话 class2 recall=0.2289 作对照：CNN 的 0.5415 更好，
    但仍不足以支撑“class2 可部署”的结论；至少还需要 3~6 条独立 class2 会话
    （不同距离/角度/背景/挥动相位）才能把会话级方差压下来。
- 建议（给 M2/M3 的下一步）：
  1. 先把 M3 RTL 通路跑通（本任务不碰 retina_event/**），用本报告的 int8 参数/ROM 做
     端到端一致性检查；
  2. 补 3~6 条 class2 独立会话后重跑本报告 §3，目标 class2 recall 会话级 >=0.7 且
     折间极差 <0.15，再谈“可部署”；
  3. class0 里只有 95 个 board_move 窗、1 条会话，建议再补 2~3 段独立位移噪声；
  4. 若上板后 class2 召回明显低于 CV，优先排查采集距离/角度与训练集的偏移，而不是
     先加网络容量。
