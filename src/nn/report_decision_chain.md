## 1. 方法：从板上 RTL 到 numpy 的 1:1 映射

### 1.1 时间映射

- 数据集每个窗口的输入覆盖 [t0-100, t0+100) ms（now=[t0,t0+100)，prev=[t0-100,t0)）。
- 板上 nn_feat 在 bin 边界 T 冻结，窗口为 [T-200, T)；令 T=t0+100，则数据集窗口 t0 恰好对应板上决策时刻 T。
- 板上每 100 ms 决策一次；数据集 stride=50 ms，因此按 t_ms 排序、以 t_rel_ms 为相对时刻后取 idx[2::2]（t0=100,200,...）。丢弃 t0=0 是因为它的 prev 窗早于录制起点、数据集里为零填充，而板上当时有真实历史；三种起点相位（t0=100/50/0 起）在敏感性里核对。
- 决策时刻 t_rel = t0+100；相位不确定性 ±50 ms（数据集网格 50 ms），见 §6 敏感性。

### 1.2 int8 前向

- 层参数从 nn_params_2cls.json 的 cnn_params.layers 读取；复用 nn/ref_cnn.py 的 forward_ref：conv 3x3 stride 2 pad 0，acc=sum(w*x)+b，算术右移 SH，clip 到 [-128,127]，conv 后 ReLU；fc 无 ReLU。
- 不用 torch：本脚本只 import numpy + ref_cnn；解释器是 trainingData/.venv（无 torch）。
- NUM_CLASSES=2：logit2 在 RTL 里钉成 -128；等价于 c=0 if s0>=s1 else 1（平局取 0），margin=|s0-s1|。conf=min(margin,31)，o_dbg_margin=min(margin,127)。

### 1.3 决策状态机

- nn_decide.v：cmb_hit=(c!=0)&&(margin>=MARGIN_MIN)；同一类连续命中 hit_cnt+1，否则重置为 1；hit_cnt>=N_CONSEC 且不在 refractory 才 pulse。
- pulse 时置 refr_cnt=REFRACTORY_CYC-1=74,999,999，之后每拍减 1；refractory 期间 hit_cnt 清 0、不再判定。按 100 ms 决策步长离散后，pulse 后第 15 个决策点（1.5 s）refr 恰好归零，可再次判定。
- act_state_cdc.v：pulse 重置 1.0 s 空闲计时；1.0 s 无 pulse 后 VALID 清零。因为 refractory=1.5 s > 1.0 s，任意两个 pulse 的 VALID 都会先清零，所以每个 pulse 恰好对应一个 VALID 上升沿；脚本对每个会话、每个组合都断言上升沿数==pulse 数。

### 1.4 指标定义

- 静默误触：y==0 且非 210307 的决策窗上的 pulse。分母同时给『静默分钟』（只算 y==0 的窗）和『会话总分钟』（任务书口径）。
- 板移噪声：会话 210307，全部 y=0；单独一列。
- class1 动作段：seg_id>=0 且 y==1 的窗口按 seg_id 分组；本数据 16 条 class1 会话共 27 段。检出 = 段内至少 1 个 pulse；重复 = 段内 >1 个 pulse。
- 挥手：y==2 的 3 条会话（210102/211950/212036）；B2 模型没有 class2，另列 pulse 数，不计入静默误触。
- 分母口径：静默分钟=非 210307 会话中 y==0 的决策窗×0.1/60；板移分钟=210307 的决策窗×0.1/60；总分钟=全部决策窗×0.1/60。
- 统计分辨率：总时长只有 1.415 min，1 个事件就是 0.71 次/分；因此『≤0.5 次/分』实际上要求 0 个事件，且 0 事件在 95% 置信下仍只能约束到约 2.1 次/分。要证明 ≤0.5 次/分至少需要 ~6 min 静默数据。这一点是离线标定的硬限制。

- 因此 conf 不能当二级过滤：在真正被接受的 pulse 上它几乎是常数 31，无法区分『高置信真动作』和『高置信误判（挥手）』。要二级过滤就用 o_dbg_margin（0..127，仍然在 127 饱和但比 31 多 4 位），或者直接提高 MARGIN_MIN。

## 7. 离线结论的可信边界

- 统计分辨率：总回放时长只有 1.415 min（849 个决策点 × 0.1 s）。1 个事件 = 1/1.415 = 0.71 次/分；因此「≤0.5 次/分」在该样本量下实际等价于「0 个事件」。
- 零事件的置信上限：即使观察到 0 个事件，按 Poisson 0 事件 95% 上限约 3/总时长，真实误触率仍可能高到约 2.1 次/分；要证明 ≤0.5 次/分至少需要约 6 min 静默数据（3/6=0.5）。
- in-sample 性质：final 2cls 模型是在全部 20 条会话（含静默、板移、挥手）上训练的 ROM 工件，本报告的回放不是留一会话泛化评估；窗级 y0 准确率 0.9988，而会话级 LOO 的 y0 recall 只有 0.9563（≈4.4% 泛化 FP）。因此 0 次静默误触只是 in-sample 下界，不能外推为现场误触率。
- 相位/步长敏感性只说明「换起点或 50ms 步长时结论不翻转」，不改变上述样本量与 in-sample 限制。

## 8. 结论与给上线的建议

1. 任务口径（静默段 + 210307）：基线 0.00 次/分，class1 动作段 27/27；推荐 24/3 仍 0.00 次/分、27/27。
2. 用户可感知口径（挥手也算误触）：3 段挥手全部被 B2 判成 class1，共 6 pulse（4.24 次/分）；任何 MARGIN_MIN × N_CONSEC 组合都不减少这 6 个，阈值调参治不了。
3. conf 长期 31 是 5-bit 饱和的必然结果（margin≥31 即 31），不是高置信证据；host 若用 conf 做过滤，实际等价于恒真。
4. 立即能做的配置改动：MARGIN_MIN 8→24（N_CONSEC 保持 3），只需改 nn_cfg.vh 参数并重综合；对静默/板移误触是更保守的先验，对挥手无效。
5. 真要降低挥手误触：按 M5 §4 回退/演进路线补 class2 数据重训三分类（或 host 侧对 class1 做时间冷却/去重），不要指望在 B2 上调阈值。
6. 离线结论的边界：final 2cls 模型是在全部 20 会话上训练的 ROM 工件，窗级 y0 准确率 0.9988，而会话级 LOO 的 y0 recall 只有 0.9563（≈4.4% 泛化 FP）。因此本报告的 0 次静默误触是 in-sample 下界；现场误触率必须用板上日志或至少 6 min 静默数据重新测。
